# Triage labels

Use this mapping for ticket triage. Record the tracker value
in the ticket's `Status:` line.

| Canonical role | Tracker value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer must evaluate the issue |
| needs-info | needs-info | Waiting for more information |
| ready-for-agent | ready-for-agent | Fully specified for autonomous agent work |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

When a skill names a canonical role, use its tracker value.
