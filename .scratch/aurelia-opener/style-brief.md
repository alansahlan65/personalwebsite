# Archival Aurelia tour direction

Reviewed 19 October 2026. This file remains an input to `build-aurelia-legacy.mjs` in this directory. That historical helper produces the superseded 40-second page-tour package and can overwrite current demo output; it is not the current header rebuild entry.

The archival film follows the original page through hero, discovery, collection, property detail, and local request states. It uses source DOM, original fonts/icons/photographs, a fixed 1920×1080 stage, and local dependencies. The screens describe a fictional hospitality concept and establish no inventory, submission, payment, or booking outcome.

The live portfolio uses the [36-second header direction](../../public/demos/aurelia/DESIGN.md), rebuilt by `node scripts/build-aurelia-header.mjs`. See [the current production record](../../docs/aurelia-opener.md) before rebuilding any Aurelia package.
