## Acceptance

- Content represents confirmed role, contribution, client/concept status, and original versus later work.
- Navigation works through direct URLs, normal/modified clicks, keyboard, touch, Back/Forward, and explicit return.
- Repeated input and interrupted motion follow the latest intent without losing focus, content, or scroll access.
- Gallery covers stay loaded during expansion; focus wins over hover; touch requires one tap.
- Case evidence remains readable with native full-source access and honest raster-resolution limits.
- Reduced motion, forced colors, enlarged text, no JavaScript, and storage/clipboard failures preserve the relevant task.
- Validate the specified responsive widths, build, types, lint, relevant browser behavior, and measured performance conditions.
- Set a production origin and review publication metadata before public release. Local tests establish only the recorded coverage.
